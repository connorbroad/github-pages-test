# CLAUDE.md - Root Project

This is an Astro-based personal website hosted on GitHub Pages. The site includes several games and content sections.

## Quick Reference

- **Build:** `npm run build`
- **Dev server:** `npm run dev` (localhost:4200)
- **Test:** `npm test` or `npm run test:watch`
- **Format:** `npm run format`

## Project Structure

- `/src/pages/` - Astro file-based routing
- `/src/components/games/` - Game implementations (solo-rpg, biimo-player)
- `/src/layouts/` - Astro layout templates
- `/public/` - Static assets

## Tech Stack

Astro 5.6, Svelte 5.25, TailwindCSS 4.1, TypeScript

## Deployment
